# MACHINE FILTER: working rules for agent sessions

Read `HANDOFF.md` first: it has the state, the folder layout and the next steps.

- **Toolchain:** set up a fresh container with `pcb/tools/setup-toolchain.sh`, then build and verify with `pcb/tools/build.sh`. The build must end with `OK` before any work is handed back.
- **Two boards, one KiCad project** (`pcb/machine-filter/`, KiKit multiboard workflow): MAIN (JLC SMD assembly, ≤ 100 × 100 mm) and CONTROL (hand-soldered: through-hole R/C and SOIC only, no SMD R/C) share one schematic and one PCB file, with the outlines side by side. `tools/separate.sh` cuts them apart into `pcb/fab/main/` and `pcb/fab/control/`. The control board's nets are prefixed `CTL_`, so no net spans both boards; keep it that way, or the PCB's DRC breaks. Every part in `boards.py` carries `board="main"` or `"control"`. Keep JLC-only parts off the control board and jacks/sockets/headers out of the JLC assembly.
- **Connectivity lives in two places that must agree:** `pcb/machine_filter.py` (SKiDL, the source of truth) and `pcb/design/boards.py` (drives the drawing). Change both; `build.sh` fails if they differ, or if the two boards joined through their headers differ from the one-circuit netlist.
- **Pin assignment follows the PCB layout** (since 2026-10-06; see the post-mortem in `HANDOFF.md`): `pcb/design/pinmap.py` (header pin order, ADC pins, op-amp sections, mux channels) is edited to match the layout, and both sources read it. Then run `pcb/tools/build.sh` without `FLOORPLAN=1` (which would overwrite it), and paste the tables from `python3 pcb/tools/doc_tables.py` into `docs/firmware-changes.md` and `docs/placement-guide.md`. The board-to-board headers are placed last.
- **Placement:** in order of importance, by function group (`pcb/design/groups.py`), each step ending in a picture for d. PCB edits go through Konnect on the live editor (`HANDOFF.md`, Tool notes).
- **Never edit the generated schematics:** `pcb/machine-filter/*.kicad_sch` are regenerated by `pcb/design/gen_sch.py`. The PCB file (`machine-filter.kicad_pcb`) is real layout work: never regenerate it with `pcb_skeleton.py --force` once parts are placed.
- **Libraries:** use the project library (`pcb/lib/`, provenance in `lib/SOURCES.md`) and KiCad's stock libraries. d prefers the existing project library over new sources.
- **Verify facts:** check pinouts and electrical facts against primary sources (datasheets, Electrosmith's Seed3 pinout CSV), not memory, because the original scripts were built on weak research. Record what was checked in `docs/design-review.md`.
- **Pin swaps change firmware too:** any layout-driven pin swap (op-amp sections, mux channels, MCU pins) means updating `docs/firmware-changes.md` (from `pinmap.py`) and the `EXPECTED` pins in `pcb/tools/check_netlist.py`.
- **How to talk to d:** d is a media studies scholar building this as a DIY project. Explain electrical reasoning plainly and give candid tradeoffs.
