# PCB layout study (Eurorack)

These two reports measure 53 open-source Eurorack PCB layouts (Avalon-Harmonics, QuinnFreedman/modular, EuroPi). They're meant to inform placement rules.

- [pcb-spacing-study.md](pcb-spacing-study.md): how close THT and SMD parts sit to jacks and pots, and to each other.
- [opamp-placement-study.md](opamp-placement-study.md): where passives sit around op-amps, how far apart neighbouring op-amps are, and suggested rules.

Each report's figures are in `images/`.
